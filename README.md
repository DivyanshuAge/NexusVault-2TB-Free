# 🎮 NexusVault & GameVault Drive

NexusVault is a 100% free desktop app designed to enhance your local storage. It gives you a virtual 2TB container to store and run heavy PC games without using up your hard drive space.

## 🔥 Key Features
* **Virtual 2TB Space:** Offload 50GB–100GB game files natively inside the app dashboard.
* **GameVault Shrinker:** Automatically compresses your local games when you aren't playing them, then restores them instantly when you click 'Play'.
* **NexusDrive P2P Network:** Connects to a free peer-to-peer network pool to back up installation files safely.

## 🛠️ Setup Instructions
1. Download `main.py` from this repository.
2. Open your terminal or command prompt and install the layout interface:
   `pip install customtkinter`
3. Run the application:
   `python main.py`
